# eva2_cortes_ain

Rediseño del home de la Municipalidad de Cholchol para Evaluación Sumativa U2 (Desarrollo Frontend).

## Estructura

- `index.html`: estructura semántica de las 8 secciones solicitadas.
- `styles.css`: estilos visuales, responsive, estados focus/hover y accesibilidad.
- `app.js`: interactividad (eventos, filtro, búsqueda, validaciones, manipulación DOM).

## Framework y librerías

- Bootstrap 5 (layout responsive + componentes)
- Bootstrap Icons

## Cobertura rápida de criterios

- **CE1 (Eventos):** `click`, `scroll`, `input`, `submit`, `DOMContentLoaded`.
- **CE2 (Formulario):** validación de nombre, correo y mensaje en tiempo real.
- **CE3 (DOM dinámico):** render/filtro de noticias, contador, mensaje de envío, estado de filtros.
- **CE4 (Framework + responsive + accesibilidad):** Bootstrap, media queries, HTML semántico, `alt`, `aria`, navegación teclado.
- **CE5/CE6 (UI/visual):** sistema de color, jerarquía tipográfica, espaciados y consistencia visual.
- **CE7/CE8 (estructura + convenciones):** separación por archivos, nombres claros de funciones y variables.

## Ejecución

Abrir `index.html` en navegador.
